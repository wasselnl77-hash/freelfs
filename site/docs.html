Install guide

Only install on a spare computer or in a virtual machine. The installer erases the whole disk you pick.

  1. Boot the live ISO from a USB stick (see Download) and log in. The user is tester, with no password.
  2. Open the FreeLFS install icon on the live desktop.
  3. Go through the steps: language, keyboard, Wi-Fi, disk, account, time zone, summary, install.
  4. When it finishes, reboot and remove the stick.

Installing next to other systems and manual partitioning are not tested yet. Use a whole disk.

FAQ

Why from scratch?

FreeLFS wants its own package manager, boot loader, shell, compositor and desktop, all in C, with no parent distro. Building the system from scratch is how it gets there.

FreeBWS or Firefox?

Firefox from the Software Store is recommended for heavy sites. FreeBWS is the light browser for 1 GB computers. It is a community project, and help is wanted: its known problems include a Cloudflare check and Google login.

Hardware support?

AMD graphics work on the one AMD laptop tested partly; other AMD chips are prepared but untested. Intel needs testers, and Intel 3D drivers come later; until then Intel uses software OpenGL. 32-bit is not planned. See the Download page for the table.

What is a rolling release?

There are no numbered releases. The packages follow the newest stable upstream releases, and the kernel is the newest 7.x stable, with 6.18 LTS as a fallback package. Before every change, flpkg takes a btrfs snapshot. At boot you can choose "Start an earlier state" from the boot menu.

How do I update?

Open the Packages app and use Update, or run flpkg upgrade --sync in the Terminal. The update notifier tells you when updates are waiting.

Roadmap (all planned)

Nothing here is finished, and no dates are set.

  • Translations: the desktop and its apps in 12 languages (en_US, en_GB, de, fr, es, it, pt_BR, nl, pl, cs, sv, tr). English is the fallback.
  • Hardware app: device overview, drivers and firmware, power and CPU, sensors, disk health, and memory settings.
  • Installer: a world map for the time zone, more keyboard layouts with a test field, a hostname and auto-login, a swap choice, a hardware check, and later disk encryption, manual partitioning and dual-boot.
