We need testers!

FreeLFS has been run mostly in virtual machines. Real computers show different bugs, and most hardware has never been tried. Every report helps.

What to test

  • Boot the live stick to the login screen and log in.
  • Wi-Fi: find a network and connect in Settings.
  • Shutdown and restart.
  • Files and USB sticks: open, copy and eject.
  • Opening images and video.
  • Sound.
  • Bluetooth.
  • The installer, in a virtual machine (the installer erases the disk you pick, so use a VM disk).

How to report

  1. Open the Terminal and run flreport.
  2. Save its output to a USB stick.
  3. Open an issue at github.com/wasselnl77-hash/freelfs/issues/new. You need a GitHub account.
  4. Include your hardware, what you did and what happened. Attach the flreport file.
