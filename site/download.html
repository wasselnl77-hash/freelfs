Download

No release published yet. The live ISO is built, but it is not on GitHub Releases yet. When it is, it will be listed at github.com/wasselnl77-hash/freelfs/releases.

The live ISO is called freelfs-live.iso and is about 843 MB. It boots from a CD image or a USB stick, and the live session keeps everything in RAM. Nothing is written to the computer's disks unless you run the installer.

Check the sha256

Compare the checksum of your copy with the sha256 value on the release page.

sha256sum freelfs-live.iso

On Windows: certutil -hashfile freelfs-live.iso SHA256

Write it to a USB stick

Option 1: Ventoy. Install Ventoy on the stick, then copy freelfs-live.iso onto it as a file. Boot the stick and choose "Boot in normal mode". Ventoy works in UEFI mode only, with Secure Boot off.

Option 2: dd (Linux).

Double-check the device. dd erases the whole disk it writes to, with no question asked. Use the stick as a whole device (for example /dev/sdb), not a partition (/dev/sdb1). Check the name with lsblk first: the size and model must match your stick. Writing to your system disk destroys your data.

lsblk
sudo dd if=freelfs-live.iso of=/dev/sdX bs=4M status=progress conv=fsync

Replace /dev/sdX with your stick's device name.

Requirements

MinimumRecommended
CPUx86_64 (64-bit Intel or AMD)same
RAM1 GB2 GB or more: the live session keeps everything in RAM
FirmwareUEFI, Secure Boot offsame
Graphicssee belowAMD (tested on one laptop)

Legacy BIOS boot is not supported: the live ISO and the installer use UEFI.

Graphics and Wi-Fi

HardwareStatus
AMD graphicsTested partly, on a Ryzen 5 7520U laptop (Radeon 610M). Other AMD chips: prepared, not tested on real hardware.
Intel graphicsPrepared, not tested on real hardware. Needs testers. Intel 3D drivers are planned for later; until then Intel uses software OpenGL.
NVIDIANot supported yet. The computer runs on its firmware display or its integrated GPU. Open-source driver (nouveau) planned.
Wi-FiRealtek rtw89 tested on one laptop. Other Intel, Realtek and MediaTek chips are included in the kernel but not tested.

The full list is in docs/HARDWARE.md. 32-bit systems are not planned.
